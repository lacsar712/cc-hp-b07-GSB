# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

顶栏「联锅对照」是独立专页（`#/compare`）：炮制员指定实验锅与对照锅两笔编号，专页并排展示两边温度、时长、结论，温度差与结论是否同向由服务端核算；质检员可打开查看，但不能指定、不能解除。对照解除后专页不再展示该对，解除动作留履历。锅次详情只是列表里的一行展示，不算专页。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 顶栏点「联锅对照」进入专页；processor 在指定区填实验锅编号 1、对照锅编号 2 后建立对照。
5. 并排区立即出现该对：实验锅 120℃ / 对照锅 40℃，中间显示服务端算出的温度差 **+80℃**，结论「异向」（放行 vs 未放行）。
6. checker 登录后能打开该专页看到并排对照，但没有指定区与「解除对照」按钮。
7. processor 点「解除对照」后，该对从生效对照区消失，出现在下方解除履历中（含解除人与解除时间）。
8. 同一锅已在生效对照中时再次指定，接口返回 409；同一笔编号不能同时作为实验锅与对照锅。
