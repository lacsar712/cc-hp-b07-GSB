# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 端口

|------|------|

| 接口 | http://localhost:8193 |

```bash
cd projects/14-herb-process-record

```

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 顶栏点「联锅对照」进入对照专页（详情页只拼两行不算专页）：
   炮制员在指定区选实验锅、对照锅两笔编号后指定，并排区应立即展示两边温度、时长、结论，
   中间为服务端算出的温度差（实验减对照）与结论是否同向。
5. checker 登录可打开对照页查看，但没有指定、解除入口（服务端同样 403）。
6. 炮制员解除对照后，该对从并排区消失，解除履历区出现一条解除记录（含指定人与解除人、时间）。
   同一对之后可重新指定。

## 联锅对照接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | /api/pairs | 炮制员 | 指定实验锅/对照锅两笔记录编号 |
| GET | /api/pairs | 登录可见 | 进行中的对照，含温度差 temp_diff、结论同向 same_direction |
| POST | /api/pairs/{id}/unbind | 炮制员 | 解除对照，解除信息写入 pot_pairs 履历 |
| GET | /api/pairs/history | 登录可见 | 已解除对照履历 |
